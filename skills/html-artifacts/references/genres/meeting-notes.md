# Meeting notes

**Use for:** summaries of meetings, calls, interviews, podcast or video transcripts.
**Not for:** a project status (`status-update.md`).

## Skeleton

```
h1  <Meeting>, <date>
.lead  The outcome in one or two sentences: what was decided
.kv  Date · Attendees · Duration · Recording/transcript link
h2  Decisions  → numbered list; each decision one sentence, with who decided
h2  Action items  → table: action | owner | due | status tag
h2  Open questions  → list, each with who follows up
h2  Discussion  → h3 per topic, a few bullets; quotes in blockquote with speaker
details  Full notes / transcript excerpts
```

## Components

`.kv`, tables with `.tag` status, `blockquote` for quotes, `<details>` for raw notes, `.timeline` for timestamps into a recording.

## Rules

- Decisions and action items first; discussion is supporting detail.
- Every action item has one owner and a date, or says "no date".
- Attribute quotes and opinions; don't attribute small talk.
- Link timestamps when there is a recording.

## Avoid

- Chronological retelling. Group by topic.
